# Link Tree

A link-in-bio page — profile photo plus a stack of pill-shaped buttons linking to the author's GitHub and demo pages. This repo is a duplicate copy of the Link-Tree repo: its page files are identical to that repo's.

## What it is

A single-page "link tree" in the style of Linktree. At the top is a circular profile photo; under the heading "All Source Code And Practice" sits a vertical stack of wide white pill buttons: **GitHub** (the author's profile), **Login** (the Login-Just-Copy demo), **Web Login** (the PortFolio demo), **Login Form** (the Login-Form demo), and **try again** (the Practice-Login-Page demo) — each opening its GitHub Pages site in a new tab. The page background is a full-screen photo, and the buttons animate on hover, growing wider with expanded letter spacing.

## Files

- `index.html` — the page: profile header, heading, and the five link buttons.
- `style.css` — full-screen background photo, circular profile image treatment, and the pill-button styling and hover animations.
- `1.PNG` — the profile photo shown at the top of the page.
- `3.jpg` — the full-page background photograph.
- `LT.ico` — the page's favicon.
- `README.md` — this file.

## Run it

Open `index.html` in a browser.
